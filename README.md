# circus-inventario

Vista pública (sin login) del inventario 2599: totales, checks RAL / CIRCUS / REDUCTO / INSUMOS con filtro, pestañas por ubicación y tabla de artículos.

- API: `src/api.js` (`API_URL`, producción).
- Empresa: `ID_EMPRESA` en `src/ViewInventario.jsx`.

```
npm install
npm run dev
npm run build
```
